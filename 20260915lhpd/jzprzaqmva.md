# hcg阴性是什么意思

> 更新时间：2026-09-15 (UTC+8)

hcg阴性是什么意思更新时间:2017-11-08

为了检测的准确性，一般医生建议做血HCG早孕检查。这样可以让我们准确的知道受孕的情况，为孕期做好准备。那么， hcg检查结果怎么看呢?hcg阴性是什么意思?

hcg阴性是什么意思人绒毛膜促性腺激素(HCG)是妊娠期由胎盘产生的一种糖蛋白，可通过肾小球排出体外，所以测定尿液中得HCG是诊断妊娠的可靠指标。本品采用纳米胶体金技术，应用层析式双抗体夹心法，检测尿液中HCG浓度，判断是否怀孕。 免疫胶体金法。也就是平常的尿试纸条，该方法由于应用广泛，方法学较成熟，检测迅速，灵敏度高.

一般可达到10-25IU/L.也就是说尿中如果HCG水平达到10，就可能检测出来。女性妊娠到0.2-1周时血清中的HCG水平就可达到5-50IU/L，而在尿中清晨尿的HCG水平最高，可接近血清的水平，因此尿HCG检测以清晨的尿最佳，阳性率最高。

使用方法

1. 撕开铝箔袋，取出验孕卡;

2. 依据型号进行操作(尿液不得直接浸湿观察区)

不能超过MAX线

条型：将试纸白色一端浸入尿液中(液面不得超过横线) ，保持10秒钟

卡型：直接将尿液滴至加样孔，约2-3滴(尿液不得直接浸湿观区);

笔型：直接将尿液淋至加样区，保持5~10秒钟。

3. 将试纸平放1分钟，等待红色条带出现;

4. 5分钟内观察结果，5分钟后判读无效

结果解释

阳性：出现两条红色条带。一条位于对照区C,另一条位于检测区T，表示已怀孕。

阴性：仅在对照区C出现一条红色条带，在检测区T无红色条带出现，表示未怀孕。

无效：5分钟在对照区C无红色条带出现，提示测试失败或试纸已失效。

当自己检查出来尿检结果，发现自己的hcg是阳性的话，那么就要重视自己的症状了，很多孕妇会出现这样的现象，但是要不是孕妇的话，出现了这样的现象后要调整好心态，而这样的结果还是怀孕的女性出现症状的几率比较大，就说明自己怀孕了，自己要调整过来自己怀孕的事实，最好相应的改善和准备，安心育儿。

血hcg正常参考数值妊娠不同时期以及各孕妇之间血清hcg绝对值变化很大，也就是说不同个体之间存在的差异比较大，因此，血hcg只可与自己比较，与别人没有可比性，。一般没有怀孕的女性血HCG<5IU/L，在妊娠最初3个月，HCG水平每2天左右约升高一倍。
